# Garet-Schriftdateien

Garet ist lizenzpflichtig und liegt deshalb nicht im Repository. Lege die Dateien hier ab,
dann nutzt das Dashboard sie automatisch (CSS `@font-face` in `assets/style.css`):

    assets/fonts/Garet-Book.woff2      (300)
    assets/fonts/Garet-Regular.woff2   (400)
    assets/fonts/Garet-Medium.woff2    (500)
    assets/fonts/Garet-Bold.woff2      (700)

Für PDF-Reports zusätzlich als TrueType, gleicher Ordner:

    assets/fonts/Garet-Regular.ttf
    assets/fonts/Garet-Bold.ttf

Fehlen die Dateien, fällt alles auf Jost zurück; das Dashboard funktioniert unverändert.
